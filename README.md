# 湾岸 MIDNIGHT — 三人称視点ハイスピードバトル

首都高・湾岸線をモチーフにした、ブラウザで動く**三人称視点のナイトレースゲーム**です。
ビルド不要・インストール不要で、`index.html` を開けばそのまま遊べます。

> **非公式のファン作品です。**
> 漫画『湾岸MIDNIGHT』へのオマージュとして個人制作したもので、権利者とは一切関係ありません。
> 登場人物・セリフ・ストーリーはすべてオリジナルです。
> 車両は実在の市販車を参考にしていますが、性能値はゲーム用に調整した数値です。

## 遊びかた

### そのまま開く
```
git clone <このリポジトリ>
cd hatahuri
```
`index.html` をブラウザで開くだけです。ただし ES モジュールを使っているので、
**ローカルの `file://` では動きません**。簡易サーバーを立ててください。

```bash
python3 -m http.server 8080
# → http://localhost:8080/ をブラウザで開く
```

### 1ファイル版をつくる
配布や共有のために、全モジュールを1枚のHTMLに束ねられます（three.js はCDNから読み込み）。

```bash
node tools/build-single.mjs dist/wangan-midnight.html https://cdn.jsdelivr.net/npm/three@0.160.0
```

`dist/wangan-midnight.html`（約160KB）はこのリポジトリにも入れてあります。
1枚だけ置ける場所（Artifact、社内Wiki、静的ホスティングなど）に貼ればそのまま動きます。

### GitHub Pages で公開する
リポジトリの Settings → Pages → Source を `main`（または任意のブランチ）の `/ (root)` に設定するだけです。
外部CDNに依存していない（three.js は `vendor/` に同梱）ので、そのまま動きます。

## モード

- **ストーリー** — 9人のライバルと1対1のバトル。勝つと賞金が入り、次の相手が出てきます。
- **フリーラン** — 交通量のある湾岸線を自由に流すモード。
- **タイムアタック** — 1周（約14.7km）のベストラップに挑戦。
- **ガレージ** — マシンの購入・チューン・カラー変更。3Dプレビュー付き。

### バトルの仕組み
アーケードの湾岸レースでおなじみの**体力ゲージ方式**です。

- 先行しているあいだ、相手のゲージが減ります。**車間が開くほど減りが速い**
- 相手のゲージがゼロになるか、400m以上離せば勝ち
- 前車の40m以内に入ると**スリップストリーム**が効き、空気抵抗が約4割減ります

### 物理まわりのメモ
- **エンジン**：回転数からトルクを引き、ギア比と最終減速比を掛けて駆動力にしています。
  最終減速比は「目標最高速でレッドに当たる」ように逆算しているので、
  ギア比チューンを上げると自動的にハイギアードになります。
- **最高速**：空気抵抗 `0.5ρCd·A·v²` とパワーの釣り合いで決まります。カタログ値の直入れではありません。
- **旋回**：前後2輪モデル（バイシクルモデル）＋摩擦円。荷重移動とダウンフォースを見ています。
- **安定化**：タイヤが支えられる旋回速度の上限を超えたぶんだけ減衰させ、
  一度スピンしたら戻せない状態を防いでいます（サイドブレーキ中はこの補正が緩みます）。
